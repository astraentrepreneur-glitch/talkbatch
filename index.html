One recording.
Several finished videos.

Arrange single- or multi-segment outputs. Preview the numbered queue. Download one plan and export it locally with Python + FFmpeg.

Re-encoded WebM, not lossless cutting. Standalone, not a LosslessCut plugin. AI-authored preview: review every output before publishing.

1. Open your recording

No upload, account or background server. This page uses a browser-local file URL; it does not send your video or plan to a service.

Choose an MP4, MOV, MKV or WebM, or load a plan.

Preview depends on your browser's codecs. If unavailable, type ranges manually; the exporter probes the actual file. Times are relative to the recording, not wall-clock time.

2. Build the output queue

Each card becomes one video. Ranges join in the order shown; overlaps/repeats are intentional if you enter them. Reorder cards to control numbered filenames.

Times: seconds, MM:SS or HH:MM:SS, with optional decimal seconds. Up to 30 outputs, 10 ranges per output, 120 ranges total. Minimum range: 0.1 seconds.

3. Export locally

    Keep talkbatch.py from the source/package. With Python 3.10+ and FFmpeg 6+ installed, run the following with your own paths in place of the uppercase placeholders:

    python3 talkbatch.py --check
python3 talkbatch.py --source SOURCE --plan PLAN --dry-run
python3 talkbatch.py --source SOURCE --plan PLAN --output NEW_DIRECTORY

    On Windows, use python if that is your Python command. Quote paths for your shell. The output directory must not exist. The exporter uses argument lists, never shell commands from this plan.

    The queue runs sequentially. A failed export stops it and writes a failure report; completed outputs stay intact. The default per-output timeout is one hour. Encoding can be slow: test a short sample before a long recording.

    Privacy & limits. Files and plans remain in this page's memory until replaced or closed; downloads are written only when requested. Browser extensions, OS swap and download history are outside this app's control. Use media you trust and have rights to process.

    Only the first video/audio streams are exported. Extra tracks, chapters, subtitles and metadata are not preserved; odd dimensions may gain a one-pixel border. Export timing is frame-boundary limited. No quality, timing, rights-clearance or production-reliability guarantee.
